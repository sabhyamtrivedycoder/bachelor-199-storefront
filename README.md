# Bachelor 199 — Storefront

A responsive landing page for **Bachelor 199**, a beginner-friendly ebook with 199 main recipes and 30 bonus recipes for cooking for one.

## Price and order status

The listed launch price is **₹149 INR**. The Shopify store is currently on a trial plan and protected by a storefront password, so checkout is not publicly available and orders cannot be placed yet. Open the store and confirm the product''s correct PDF delivery before changing the page to accept orders.

Recipe ingredient costs are estimates for the portion used, not a guarantee; prices vary by city, season, retailer and brand.

## GitHub Pages

This is a static site. GitHub Pages serves it over HTTPS after the **Deploy Bachelor 199 site to GitHub Pages** workflow succeeds. In repository **Settings → Pages**, select **GitHub Actions** as the build and deployment source if it is not already selected.

The book helper answers a short set of common questions locally. GitHub Pages does not run a backend API, so it is not an open-ended generative AI assistant.

## Preview locally

From this folder, run:

```powershell
python -m http.server 8000
```

Then open http://localhost:8000.

No API keys, ebook download, or customer data are included in this public repository.
